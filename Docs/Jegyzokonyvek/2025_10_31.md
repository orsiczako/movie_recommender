## Jegyzőkönyv

### 1. Sprint 1 eredményei

* A projekt alapstruktúrája teljesen elkészült, amely magában foglalja a backend és frontend mappastruktúra kialakítását, a környezeti konfigurációk és alapvető dependenciák beállítását.
* A felhasználói hitelesítési modul tervezése és részleges implementálása megtörtént, beleértve a regisztráció, bejelentkezés és jelszókezelés alapvető funkcióit.
* A filmadatok kezelése a TMDB API integrációval elindult, alapvető CRUD műveletek implementálásra kerültek a backend oldalán.
* A soundtrack keresési logika első verziója elkészült, amely lehetővé teszi filmcím alapján a releváns zeneszámok azonosítását.
* Dokumentációs szinten a sprint során készített kód alapjai és API specifikációk rögzítésre kerültek, ami elősegíti a következő sprint fejlesztését.

### 2. Sprint 2 célkitűzései

* **Backend fejlesztés:**

  * Spotify API integráció megkezdése, amely magában foglalja a hozzáférési tokenek biztonságos kezelését, a keresési lekérdezések optimalizálását, valamint az albumok és lejátszási listák lekérdezésének lehetőségét.
  * Hibakezelés és logolás implementálása a Spotify API hívásokhoz, hogy biztosított legyen a stabil működés és a könnyebb hibakeresés.
* **Frontend fejlesztés:**

  * Felhasználói profiloldal alapstruktúrájának elkészítése, amely tartalmazza az alapvető felhasználói információk megjelenítését és szerkesztését.
  * Filmek böngészéséhez szükséges komponensek elkészítése, beleértve a részletes információs nézetet, valamint a soundtrackek listázását.
  * Reszponzív design kialakítása a különböző képernyőméretek támogatására.

### 3. Feladatok priorizálása

* **Backend:**

  * Elsődleges feladat a Spotify kereső API végpontok implementálása és a tokenek biztonságos kezelése.
  * Másodlagos feladat a hibakezelés és logolás fejlesztése, a hibák követhetőségének biztosítása érdekében.
* **Frontend:**

  * Alapvető felhasználói felület létrehozása Vue.js keretrendszer segítségével, a későbbi funkciókhoz szükséges keretrendszer biztosítása.
  * Filmek és soundtrackek böngészéséhez szükséges UI komponensek elkészítése és tesztelése különböző képernyőméreteken.

### 4. Technikai kihívások és megoldási javaslatok

* Spotify API keresések esetében szükséges a lekérdezések pontos kezelése, figyelembe véve az esetleges duplikációkat, nagybetű/kisbetű érzékenységet és az API limitációit.
* A frontend és backend közötti adatkommunikáció optimalizálása szükséges a késleltetés minimalizálása érdekében.
* A fejlesztőcsapat javasolja a dokumentáció folyamatos frissítését, különösen az API integrációk és a hibakezelés kapcsán, hogy a későbbi sprint során minimalizálható legyen a félreértés és a felesleges refaktorálás.
