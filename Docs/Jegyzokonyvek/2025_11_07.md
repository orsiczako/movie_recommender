## Jegyzőkönyv

### 1. Sprint 2 eredményei

* **Spotify API integráció:**

  * A hozzáférési tokenek kezelése és automatikus frissítése működőképes, a rendszer képes a token lejáratok kezelésére.
  * A soundtrack keresési funkció bővítése megtörtént, most már lehetőség van albumok és lejátszási listák lekérdezésére, azonban a keresési algoritmus finomítása még szükséges a pontosabb találatokhoz.
* **Frontend fejlesztés:**

  * A felhasználói profiloldal alapjai elkészültek, az alapvető adatok megjelenítése és szerkesztése biztosított.
  * A filmek böngészése és a részletes információk megjelenítése funkcionálisan működik, a UI alapvető reszponzív kialakítással rendelkezik.
* **Dokumentáció:**

  * A fejlesztési folyamat dokumentációja frissítve lett, az API hívások és az adatbázis-kezelés alapvető specifikációi rögzítésre kerültek.

### 2. Sprint 3 célkitűzései

* **Soundtrack keresési funkció bővítése:**

  * Pontosabb keresési algoritmusok implementálása a releváns találatok növelése érdekében, beleértve a filmcím, album, lejátszási lista és kulcsszavak kombinált keresését.
  * Felhasználói preferenciák figyelembevétele a keresések során, így személyre szabott találatok biztosítása.
* **Felhasználói preferenciák kezelése:**

  * A preferenciák mentése és betöltése az adatbázisból, valamint azok dinamikus frissítése a felhasználói interakciók alapján.
  * Felhasználói beállítások kezelése a frontend oldalon, lehetőség a beállítások megtekintésére, módosítására és visszaállítására alapértelmezett értékekre.

### 3. Hibák és kockázatok

* **Spotify API kezelése:**

  * A válaszok feldolgozása további fejlesztést igényel, különösen a nagyobb lejátszási listák és albumok esetén, valamint a hibás vagy hiányos API válaszok kezelése szükséges.
* **Integrációs problémák:**

  * A frontend és backend adatstruktúrák egységesítése elengedhetetlen a stabil működéshez.
  * Esetenként a keresési eredmények nem megfelelő formátumban érkeznek a frontend felé, ami további tesztelést és hibajavítást igényel.
* **Kockázatok:**

  * A keresési algoritmus finomítása és a felhasználói preferenciák integrálása során előfordulhat késleltetés az eredmények megjelenítésében, ami UX problémát okozhat.
  * Adatbázis-kezelési hibák vagy hibás mentések esetén a felhasználói preferenciák elveszhetnek, ezért a hibakezelés és biztonsági mentés kiemelt feladat.
